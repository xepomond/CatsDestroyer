# 🐾 PW Classic Cats Profit & Arbitrage Tracker

> **Полностью бесплатная (0$)** система круглосуточного отслеживания цен котов на **dbase.pwclassic.net/cats**, поиска арбитражных сделок («купи дешевле — продай скупщику сразу»), динамики рынка и мгновенных уведомлений в Telegram.
> 
> **Работает 24/7 в облаке GitHub Actions** — ваш компьютер включать не требуется!

---

## 🚀 Что умеет система

1. **Мгновенный арбитраж (Вилки):**
   * Сравнивает минимальную цену продажи с максимальной ценой скупки другими котами.
   * Находит сделки вида: *Купил у кота А -> Сделал 5 шагов -> Продал коту Б*.
   * Показывает ники котов, названия лавок, точные внутриигровые координаты `(X, Y)` и объем доступного товара.
2. **Анализ сливов и скидок:**
   * Отслеживает товары, которые выставлены на 30%+ дешевле медианной цены за последние 24 часа (ошибки нулем, срочные сливы).
3. **Мобильная Web-панель (Telegram WebApp):**
   * Красивый адаптивный темный интерфейс (Tailwind CSS).
   * Копирование координат кота в один клик.
   * Фильтры по категориям (Ресурсы, Трава, Камни, ХХ, Скилы, Популярное) и поиск по названию.
   * Открывается в любом браузере или прямо внутри Telegram в виде Mini App.
4. **Уведомления в Telegram:**
   * При обнаружении выгодной сделки бот присылает карточку с профитом и координатами.
   * Встроенная защита от спама: бот не дублирует одно и то же сообщение каждые 20 минут.

## 📋 Пошаговая инструкция по запуску (за 5 минут)

### Шаг 1. Создайте Telegram-бота (1 минута)
1. Откройте в Telegram диалог с официальным ботом [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя (например: `PW Cats Alert`) и username (например: `my_pwclassic_cats_bot`).
4. Скопируйте полученный **HTTP API Token** (выглядит как `7123456789:AAH...`).
5. Нажмите кнопку `/start` в вашем созданном боте, чтобы разрешить ему писать вам сообщения.

### Шаг 2. Узнайте свой Telegram ID (30 секунд)
1. Откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram.
2. Он пришлет ваш цифровой **Id** (например: `123456789`).

---

### Шаг 3. Загрузите этот проект на GitHub (Бесплатно)
1. Зарегистрируйтесь или войдите на [GitHub.com](https://github.com).
2. Нажмите зеленый значок **«New»** (Создать новый репозиторий).
3. Назовите его, например: `pw-cats-profit`.
4. Сделайте его **Public** (для публичных репозиториев GitHub Actions **полностью безлимитны и бесплатны**).
5. Загрузите файлы из этой папки (`scanner`, `items_db.json`, `requirements.txt`, папку `site` и папку `.github`) в репозиторий:
   * Либо через кнопку **«uploading an existing file»** прямо на странице репозитория в браузере.
   * Либо через Git (если установлен):
     ```bash
     git init
     git add .
     git commit -m "feat: initial commit"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/pw-cats-profit.git
     git push -u origin main
     ```

---

### Шаг 4. Добавьте секреты в GitHub
Ваш токен и chat ID хранятся в защищенном хранилище GitHub Secrets и никогда не видны публично.

1. В вашем репозитории перейдите во вкладку **Settings** (Настройки) -> слева в меню **Secrets and variables** -> **Actions**.
2. Нажмите **New repository secret**:
   * Имя: `TELEGRAM_BOT_TOKEN`
   * Значение: токен вашего бота из Шага 1.
3. Нажмите **Add secret**.
4. Создайте второй секрет:
   * Имя: `TELEGRAM_CHAT_ID`
   * Значение: ваш цифровой ID из Шага 2.
5. *(Опционально)* Секрет `WEBAPP_URL`: ссылка на сайт из Шага 5 (добавите после включения Pages).

---

### Шаг 5. Включите сайт (GitHub Pages)
1. В настройках репозитория (**Settings**) перейдите в раздел **Pages** (слева в меню).
2. В разделе **Build and deployment**:
   * **Source**: выберите `Deploy from a branch`.
   * **Branch**: выберите `gh-pages` (эта ветка создастся автоматически после первого запуска сканера) и папку `/ (root)`.
3. Нажмите **Save**.
4. Через 1-2 минуты ваш сайт будет доступен по адресу:  
   `https://ВАШ_ЛОГИН.github.io/pw-cats-profit/`

---

### Шаг 6. Первый тестовый запуск
1. В репозитории откройте вкладку **Actions**.
2. Слева выберите workflow **PW Cats 24/7 Arbitrage Scanner**.
3. Справа нажмите кнопку **Run workflow** -> **Run workflow**.
4. Через ~1–2 минуты сканер завершит работу:
   * В Telegram придут уведомления по найденным вилкам!
   * Обновятся данные на вашем сайте!
5. Далее сканер будет запускаться **автоматически каждые 20 минут 24/7** без вашего участия.

---

### Шаг 7. (Бонус) Как прикрепить сайт к боту (Telegram Mini App)
Чтобы сайт открывался прямо в Telegram по удобной кнопке в меню:
1. Откройте [@BotFather](https://t.me/BotFather) и введите `/mybots`.
2. Выберите вашего бота -> **Bot Settings** -> **Menu Button** -> **Configure menu button**.
3. Отправьте ссылку на ваш GitHub Pages сайт:  
   `https://ВАШ_ЛОГИН.github.io/pw-cats-profit/`
4. Введите название кнопки: `Маркет котов` или `Вилки цен`.
5. Теперь в левом нижнем углу диалога с ботом появится кнопка, открывающая мобильный WebApp в одно касание!

## ⚙️ Настройки и фильтры

В файле `.github/workflows/scanner.yml` (или в `scanner`) можно настроить:
* `MIN_PROFIT_ALERT`: минимальный профит в монетах для отправки в Telegram (по умолчанию `30000`). Если хотите получать только крупные сделки, поставьте `100000`.
* `MIN_MARGIN_ALERT`: минимальный процент маржи (по умолчанию `5.0%`).
* `cron: '*/20 * * * *'`: интервал проверки (каждые 20 минут).
